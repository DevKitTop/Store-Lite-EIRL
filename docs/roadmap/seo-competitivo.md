# Ficha de Plan — SEO Competitivo / de Crecimiento (Add-on)

> **Feature:** capa de SEO para que un seller **supere a su competencia local**,
> vendida como add-on o tier pago. Separada de la _higiene técnica_ (que es
> gratis y para todos).
> **Estado:** Idea registrada. **Prioridad:** Alta.
> **Registrado:** 2026-08-31

---

## Principio rector

Store Lite vende **"tené tu negocio"**, no SEO. Por eso:

- **Higiene técnica SEO** (canonical, sitemap, JSON-LD, OG images, SSR) →
  **gratis, para todos.** Es el piso de calidad. Si falta, la plataforma se ve
  rota y google castiga la reputación del dominio. **No se cobra.**
- **SEO competitivo / de crecimiento** → **se vende** como add-on pago.

> Misma lógica que Shopify/Wix: el SEO básico viene de fábrica; lo avanzado y
> el dominio viven detrás del pago.

---

## Qué incluiría el plan pago (candidato)

- **Dominio propio** (`mitienda.com`) — el feature estrella, ver
  [custom-domains-premium.md](./custom-domains-premium.md).
- **Analytics de búsqueda** (qué palabras traen tráfico, posiciones).
- **SEO avanzado configurable por el seller** con SERP preview y sugerencias IA.
- **Sitemap prioritario / envío a Google Search Console**.
- **"Aparecer en Google Maps"** (LocalBusiness + geodatos robustos).
- **Alertas / checklist** de mejoras.

---

## Qué NO va en el plan pago

- Canonical tags
- Sitemap por tenant
- JSON-LD (LocalBusiness / Product)
- OG images
- SSR/SSG para botabilidad
- Metadata dinámica base

Todo eso es higiene y ya va al core para todos.

---

## Prioridad dentro del roadmap

1. **Primero: la capa técnica SEO (core, para todos).** Sin eso, el plan pago
   no tiene base y la plataforma se ve mal. Ver `tasks-pendient/` (tasks de SEO).
2. **Después: dominio propio** como tier premium (el diferenciador más vendible).
3. **Al final: analytics / herramientas avanzadas** (depende de tener tráfico y dominio).

---

## Próximo paso sugerido

Cuando el core SEO esté implementado, lanzar el dominio propio como PR piloto
con un seller de confianza, medir, y recién ahí escalar.
