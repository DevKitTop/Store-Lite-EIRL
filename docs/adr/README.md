# Architecture Decision Records (ADRs)

Este directorio contiene los registros de las decisiones arquitectónicas importantes tomadas en el proyecto.

## ¿Qué es un ADR?

Un ADR es un registro de una decisión de diseño técnica significativa que incluye el contexto de por qué se tomó y las consecuencias de dicha decisión.

## Estructura

Cada registro tiene un número secuencial y sigue este formato:

- **Status**: Proposed, Accepted, Deprecated, Superceded.
- **Context**: ¿Cuál era el problema?
- **Decision**: ¿Cómo lo resolvimos?
- **Consequences**: ¿Qué ganamos y qué perdimos (trade-offs)?
